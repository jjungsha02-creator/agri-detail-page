# agri-detail-page

농산물 온라인 판매를 위한 **상세페이지 기획안 자동 생성 스킬**입니다.  
Claude Code에서 `/agri-detail-page` 슬래시 커맨드로 실행합니다.

과일명과 핵심문구만 입력하면, 실제 제작자가 바로 쓸 수 있는 완성형 기획안을 제공합니다.

---

## 무엇을 만들어주나요?

쿠팡, 스마트스토어, 와디즈 등 온라인 판매 채널에 올릴 농산물 상세페이지 기획안을 11단계로 작성합니다.

| 단계 | 내용 |
|------|------|
| 1 | 입력 정보 정리 |
| 2 | 핵심문구 해석 |
| 3 | 고객 구매 불안 정리 |
| 4 | 와디즈 벤치마킹 분석 (5개 이상 수집 → 후킹 유형 분류 → 3개 이상 선별) |
| 5 | 첫 화면 후킹 문구 (6가지 유형별 제안) |
| 6 | 상세페이지 전체 흐름 설계 |
| 7 | 섹션별 상세 기획안 |
| 8 | 이미지 컷 리스트 |
| 9 | 디자인 방향 |
| 10 | 구매 전 안내 문구 |
| 11 | 최종 검수표 (15개 항목) |

## 설치 방법

### Mac / Linux
```bash
git clone https://github.com/jjungsha02/agri-detail-page.git ~/.claude/skills/agri-detail-page
```

### Windows
```powershell
git clone https://github.com/jjungsha02/agri-detail-page.git "$env:USERPROFILE\.claude\skills\agri-detail-page"
```

설치 후 Claude Code를 재시작하면 `/agri-detail-page` 커맨드를 사용할 수 있습니다.

## 사용 방법

Claude Code 채팅창에서 슬래시 커맨드로 실행합니다.

```
/agri-detail-page 사과 상세페이지 기획해줘. 핵심문구는 꿀사과, 비파괴 당도선별
```

```
/agri-detail-page 수박 기획해줘. 핵심문구: 씨없는 꿀수박
```

---

## 입력 형식

**필수**
- 과일명 / 농산물명
- 핵심문구

**선택** (없으면 "확인 필요"로 표시)
- 품종, 산지, 수확 시기, 크기/중량, 맛 특징, 식감, 당도
- 선별 방식, 배송 방식, 보관법, 후숙 여부
- 타깃 고객, 가격대, 주의사항, 교환·반품 기준

> 핵심문구가 없을 때는 상품 정보를 바탕으로 후보 5개를 먼저 제안합니다.

## 주요 특징

- **와디즈 벤치마킹 재조합 원칙**: 특정 페이지를 그대로 따라 하지 않습니다. 여러 레퍼런스의 설득 구조를 추출해 해당 농산물에 맞게 새로 작성합니다.
- **후킹 유형 6가지 분류**: 문제 제기형 / 결과 제시형 / 권위 강조형 / 비교 설득형 / 스토리형 / 혜택 강조형
- **확인되지 않은 정보는 만들지 않습니다**: 당도, 판매량, 인증, 수상 내역은 제공된 정보가 없으면 "확인 필요"로 표시합니다.
